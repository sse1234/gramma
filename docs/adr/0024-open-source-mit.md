# 24. Open source under MIT, free forever

Date: 2026-08-28

## Status

Accepted

## Context

gramma is ready to prepare for release. The intent from the start:
completely free — no up-front price, no paid modules, no analytics
frameworks — and open source, so the repository goes public.

Going public turns every bundled byte into a distribution. That
required a license review of everything the repository carries.

## Decision

**License: MIT**, copyright Stephan Schmid-Eilber. The workspace
crates (`gramma-core`, `rust_lib_gramma`) declare `license = "MIT"`.

**Dependency audit** (2026-08-28, all green):

- Rust: every crate in the dependency tree is MIT, Apache-2.0, BSD,
  Zlib, 0BSD, Unlicense, or Unicode-3.0 — all permissive, all
  MIT-compatible. `allo-isolate` publishes no license field but ships
  an Apache-2.0 LICENSE file.
- Dart/Flutter: every hosted package is BSD-3, MIT, or Apache-2.0;
  the Flutter SDK itself is BSD-3.
- Vendored: `app/rust_builder/cargokit` is MIT (Matej Knopp) and
  keeps its LICENSE file — our PATH patch stays under that license.
- Fonts: Literata, Gentium Plus, and Gentium Book Plus are SIL OFL
  1.1; their license texts ship next to the font files in
  `app/fonts/`. OFL content stays OFL — it is bundled, not relicensed.
- The `hyphenation` crate embeds hyph-utf8 patterns, which carry
  their upstream permissive licenses.

**Content stays out of the repository.** No SWORD modules, no
publisher texts — the test fixtures are generated by our own
`tools/make_sword_fixture.py`. Users import their own modules.

**The bundled reading plan leaves the repository until permission
is granted.** It was converted from a publisher's printed plan — a
third-party curated selection, and curation can enjoy protection
even where bare verse references are facts. Consistent with the
ADR 0002 stance on publisher content (ask first, never assume), the
plan JSON is removed from the tree *and from git history* before the
repository goes public; the converter and data live on privately and
return with a credit line once the publisher grants permission. The
reading-plan feature discovers any `assets/plans/*.json` at startup
and stays dormant — menu entry hidden — while none is bundled.

## Consequences

- The repository is public; the app will ship free with no analytics
  and no paid anything. Monetization is a non-goal, permanently.
- The one-time history rewrite (purging the plan JSON) changed all
  commit hashes after its introduction; existing clones must be
  re-cloned. Done once, before the repository had any other clones.
- MIT permits commercial forks; publisher agreements (when they come)
  and every publisher text remain outside the code license — the
  repo never carries content it has no right to carry.
- New dependencies inherit a review duty: permissive licenses only.
